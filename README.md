# Proof-of-Assay — Verifiable Mining Audit Agents

> **Status: FIXTURE / LOCAL.** Synthetic data and deterministic rules only.
> No live Nosana deployment and no live Arweave anchor are claimed yet.
> The Nosana job definition in `nosana/` is a planned deployment, not a deployed service.

An audit agent pattern for mining payables: assay certificates and supplier
invoices are reconciled lot by lot, exceptions are priced as cash at risk,
and every decision is written into a SHA-256 hash chain that anyone can
re-verify. The planned live version serves an open-weight model
(Qwen2.5-1.5B-Instruct via vLLM) on Nosana decentralized GPUs and anchors
the receipt chain on Arweave; this repo proves the audit + verification
layer reproducibly today, with those integrations honestly badged as pending.

Built for the HackerNoon **Decentralize AI** hackathon (Round 1, deadline
Oct 31, 2026). Entry is a HackerNoon article — see `ARTICLE.md` (DRAFT, not published).

## Reproduce

```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/reproduce.py     # writes results.json
python scripts/verify_chain.py  # PASS
python scripts/verify_chain.py --tamper  # FAIL (tamper demo)
pytest -q                       # 35 tests
streamlit run streamlit_app.py  # verifier UI
```

## How verification works

`expected = tonnes x contracted_price`; variance, grade and quantity
mismatches flag exceptions (see `proof_of_assay/audit.py`). Each decision
becomes a hash-chain entry: `sha256(prev_hash | index | type | canonical_payload)`.
Changing any payload breaks `verify_chain` — the Streamlit app demos this
live (tamper toggle -> FAIL).
